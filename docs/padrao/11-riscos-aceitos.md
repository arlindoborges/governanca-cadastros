# Riscos de Segurança Aceitos

Este é o registro exclusivo de exceções de segurança formalmente aceitas para este projeto. Pendências de produto e sugestões comuns não pertencem aqui.

## Formato obrigatório

Cada entrada deve conter:

- identificador e título;
- data da aceitação;
- severidade;
- componente afetado;
- descrição e cenário de exploração;
- justificativa objetiva;
- controles compensatórios;
- responsável pela aceitação;
- prazo de revisão ou expiração;
- condição que revoga a aceitação.

## Estado atual

Não há riscos de segurança formalmente aceitos.

A autenticação ainda não definida é uma decisão pendente de arquitetura, não um risco aceito para produção. O sistema não deve ser publicado para usuários reais enquanto essa decisão permanecer aberta.
